                            TROUBLESHOOTING
================================================================================

Issue: "command not found: latexmk"
Solution: Install TeXLive or MacTeX
   $ brew install latexmk    (macOS)
   $ apt install latexmk     (Ubuntu/Debian)

Issue: Pre-commit script fails with permission denied

Issue: Terminology check fails

   See .claude/skills/standards/terminology-consistency.md

Solution: Check for missing packages or syntax errors
