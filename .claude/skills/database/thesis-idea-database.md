# 論文想法資料庫 (Thesis Idea Database)

此 Skill 包含了使用者的核心論文想法、見解以及相關的 AI 輔助分析與實驗設計。在協助使用者撰寫、潤稿或結構重組論文時，**必須**優先參考此資料庫中的內容。

## 資料庫結構與權重原則

資料庫中的每個想法皆分為以下兩個主要部分，Agent 在處理時需賦予不同權重：

1. **🗣️ 使用者真實想法 (User's Core Thought) - [極高權重]**
   - 這是使用者親自撰寫的文字，代表了其真實的理解、思路與說話口吻。
   - **操作準則：** 在協助潤稿、擴寫或生成內容時，必須極力保留這些段落的核心語意、邏輯流向與個人口吻，將其作為整段敘述的主幹，不得隨意扭曲或過度 AI 化。

2. **🤖 AI 佐證資料與深度研究 (Agent's Supporting Evidence) - [參考/輔助權重]**
   - 這是過去 AI 提供給使用者的回應、分析策略或實驗驗證建議。
   - **操作準則：** 這些內容應被視為客觀的補充與佐證資料，用於增強論述的說服力、提供數據支撐或擴充技術細節。Agent 可以根據當下論文的學術上下文，對這些內容進行適當的改寫、精簡或學術化轉換。

## 查閱指南

- 在進行任何論文章節的撰寫、修改或大綱規劃前，請先查閱 `ideas/` 目錄下相關的想法文件。
- 確保輸出的內容邏輯與這些核心想法保持絕對一致。
- 詳細觀察每一個想法文件中的「關聯性 (Related Ideas)」，以確保整篇論文的脈絡連貫，並將孤立的想法編織成完整的學術論證。

## 目錄結構
- `README.md`: 提供給使用者與 Agent 維護、更新此資料庫的指南與 Prompt 範本。
- `ideas/`: 存放各個獨立想法的目錄。
