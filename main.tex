\[
\hat{J}_k = \alpha \hat{J}_{k-1} + (1-\alpha)\, \Delta t_k,
\]
where $0<\alpha<1$ is a smoothing factor. The desired offset $\delta$ that aligns the scheduler transmission with the PHY deadline is
\[
\delta_k = T_{\text{deadline}} - (\Delta t_k + \hat{J}_k).
\]
The offset is then converted to frame and slot indices:
\[
 f_k = \left\lfloor \frac{\delta_k}{T_{\text{frame}}} \right\rfloor,\qquad
 s_k = \left\lfloor \frac{\delta_k - f_k T_{\text{frame}}}{T_{\text{slot}}} \right\rfloor,
\]
where $T_{\\text{frame}} = N_{\\text{frame}} T_{\\text{slot}}$.

The scheduler applies $(f_k,s_k)$ to the scheduling request such that the transmitted data arrives at the O-DU Low exactly at the required PHY boundary.

\section{Proposed Method}
In this work we propose a closed‑loop timing adjustment mechanism that integrates the dynamic algorithm described in Section~II‑C with the O‑DU scheduler. The method consists of three stages:

1. **Timing Feedback Collection** – O‑DU Low measures the actual transmission time of each downlink subframe and reports a timing offset $\\Delta t$ to the O‑DU High via the FAPI interface.
2. **Offset Computation** – The dynamic algorithm at O‑DU High processes $\\Delta t$ using the EMA model above and computes the trigger timing offset $(f,s)$.
3. **Scheduler Adaptation** – The computed offset is injected into the MAC scheduler’s timing parameters so that the next scheduling request is shifted accordingly.

The algorithm operates on a per-slot basis, ensuring that the control loop latency remains below one subframe ($\leq$ 0.5\,ms). By continuously adapting to the measured jitter, the system can compensate for virtualization-induced delays and maintain tight synchronization between the VNF and the hardware-accelerated PHY.
