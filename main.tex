\section{Introduction}
\subsection{Introduction}

\textcolor{blue}{In recent years, the Open Radio Access Network (O-RAN) architecture has become popular.
O-RAN allows for more flexible network deployments.
The Network Functional Application Platform Interface (nFAPI) is an important part of this architecture.
nFAPI helps split the O-RAN Distributed Unit (O-DU) into O-DU High and O-DU Low parts.
This functional split separates the Media Access Control (MAC) layer and the Physical (PHY) layer.
Figure~\ref{fig:O-RAN-nFAPI} shows the O-RAN nFAPI split architecture.}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\columnwidth]{figures/O-RAN-nFAPI.png}
  \caption{O-RAN nFAPI functional split architecture.}
  \label{fig:O-RAN-nFAPI}
\end{figure}

\textcolor{blue}{According to the nFAPI specification, the Virtual Network Function (VNF) includes Layer 2 and Layer 3 operations.
The Physical Network Function (PNF) handles the Layer 1 Physical layer processing.
Deploying the VNF and PNF on different machines causes several challenges.
Strict slot synchronization is required between these distributed components.
Different traffic profiles affect the latency between the VNF and PNF.
Figure~\ref{fig:Scheduler-to-PNF-latency} shows the relationship between different traffic types and the VNF-PNF latency.}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\columnwidth]{figures/Scheduler-to-PNF-latency.png}
  \caption{Observation of latency between VNF scheduler and PNF under different traffic loads.}
  \label{fig:Scheduler-to-PNF-latency}
\end{figure}

\textcolor{blue}{To lower deployment costs, operators often want to deploy Split-6 nFAPI gNBs over non-ideal networks.
However, unpredictable network latency in these environments introduces significant challenges for MAC scheduler timing.
Figure~\ref{fig:Non-Ideal-Latency} shows the latency jitter in a non-ideal deployment.
Existing open-source solutions, such as OpenAirInterface (OAI), provide basic nFAPI support.
However, they do not fully comply with the nFAPI specification for delay management.
Therefore, they cannot handle the unpredictable latency challenges.
To address these issues, this paper proposes a dynamic trigger scheduler adjustment algorithm.
Our proposed algorithm fully complies with the specification.
We verify the effectiveness and benefits of this dynamic adjustment through systematic experiments.}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\columnwidth]{figures/Non-Ideal-Latency.png}
  \caption{Impact of unpredictable network latency in a non-ideal environment.}
  \label{fig:Non-Ideal-Latency}
\end{figure}
